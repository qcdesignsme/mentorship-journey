# The first-year mentorship journey

An interactive journey map of a first-year mentorship program at Mentor Collective, built from 14 research studies with about 100 mentors and mentees.

Live page: https://qcdesignsme.github.io/mentorship-journey/

Research and design by Qian Chen ([qcdesigns.me](https://qcdesigns.me)). Illustrations: Open Peeps by Pablo Stanley, CC0.

`index.html` is the whole page (self-contained). `source/` holds the content (`data.py`), layout (`template.html`) and the build script; the build reads the Open Peeps faces from a local folder set in `build.py`.
